## MBD 是什么？

MBD（Model-Based Definition，基于模型的定义）是一种用集成三维模型完整表达产品定义信息的方法。它将几何信息、尺寸、公差、材料、工艺等信息全部绑定在三维模型上，彻底告别二维工程图。

## 为什么要做 MBD？

传统二维图纸模式下：

- 设计意图传递有损耗，工艺和制造端需要"翻译"图纸
- 更改链条长，设计变更到图纸更新存在时间差
- 质量问题追溯困难，信息散落在多个系统中

MBD 带来的核心价值：

```
设计 → 工艺 → 制造 → 检验
  ↑      单一数据源贯穿全流程      ↑
```

## 落地过程中的关键难点

### 1. 标准建立

MBD 推广的第一步是建立企业级标注规范：

- **PMI 标注规范**：尺寸、公差、表面粗糙度、形位公差的标注规则
- **视图管理规范**：不同角色看到不同信息视图
- **命名与编码规范**：特征命名、层管理、属性定义

### 2. 工具链打通

```
CATIA (设计) → 3DE (数据管理) → DELMIA (工艺仿真) → 检验系统
```

每个环节都需要数据无缝传递，这对系统集成提出了很高的要求。

### 3. 人员转型

最难的往往不是技术，而是人：

- 设计师要从"画图思维"转向"建模思维"
- 工艺员要学会直接从三维模型获取信息
- 检验员要掌握三维标注的识读

## 实战经验分享

在某航空航天项目中，我们采用了分阶段推进的策略：

1. **试点阶段（3个月）**：选择典型零件，验证标注规范和工具链
2. **推广阶段（6个月）**：扩展到整个产品线，建立培训体系
3. **深化阶段（持续）**：与工艺仿真、检验系统集成

关键成功因素：

- 高层支持与资源保障
- 完善的标注标准与模板库
- 持续的培训与辅导机制
- 分阶段验收与价值量化
